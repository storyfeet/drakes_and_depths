
Character Building
==============



Characters need the following stats.

* Primary : dex str wisdom....
* Values : Things that drive them to action : Love, glory, money.
* Compulsions : Things they MUST DO when triggered.
* Skills : More specific abilities that not everyone can do. 
* Disadvantages : Specific things that make the characters life difficult
